## Project State

### Technology Stack
- **Runtime**: Cloudflare Workers (D1, KV, R2)
- **Backend**: Hono.js 4.6 + Drizzle ORM + Zod
- **Frontend**: React 19 + TanStack Router + Tailwind CSS 4.0
- **Testing**: Vitest (unit) + Playwright (E2E)
- **Auth**: Google OAuth 2.0 with session-based cookies

### Key Patterns Established
- Multi-tenant architecture (users → accounts → roles)
- 7-tier RBAC: ADMIN, MANAGER, EDITOR, AUTHOR, VIEWER, BILLING, ANALYTICS
- Audit logging for all state changes
- Soft deletes with restore capability
- Transaction IDs for request tracing
